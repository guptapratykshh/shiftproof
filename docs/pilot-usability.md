# Observed pilot acceptance sessions  -  not yet conducted

Recruit five intended workers and two supervisors from the proposed factory. Record each participant’s language, smartphone/browser familiarity and relevant job responsibility; avoid collecting unnecessary personal details. Obtain consent for observations and any study recordings. Keep measurements outside the public demo.

For each participant, test these tasks on their own phone:

| Task | Success condition | Record |
|---|---|---|
| Activate and return using employee ID | Correct organization, no email required | Time, help, password/activation errors |
| Record an assigned update | Audio is attached to the item chosen at capture start | Time, mistakes, help, transcript corrections |
| Navigate or refresh during capture | Stay, keep draft or explicitly discard; no silent loss | Recovered capture ID, item, audio duration |
| Lose network and reconnect | Draft stays local; fresh authorization before send; no duplicate | Recovery time, queued status, source playback |
| Find outstanding work | No critical hold or required task omitted | Missed/required items, source-finding time |
| Receive a handover by voice | Listen, record readback, confirm displayed version | Help, correct version, omissions |
| Report a task complete | Assigned worker reports; supervisor verifies separately | Errors, role confusion, time |
| Review/recover a failed report (supervisors) | Original evidence retained, reason logged | Time, source correctness, mistakes |

Counterbalance raw transcripts versus the ShiftProof handover and voice versus manual entry. Report individual results as well as totals: completion rate, help needed, time, omissions, transcript edits and corrections. This small study does not establish representative factory usability.

Any wrong-item recording, unauthorized clearance, lost submission or missed critical hold blocks release. Record reproduction steps, fix it, and repeat the affected session. No participant results should be filled in from automated tests or scripted browser runs.
